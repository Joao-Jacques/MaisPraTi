Tecnologias

REACT

React é uma biblioteca JavaScript para construir interfaces de usuário. Ela permite criar componentes reutilizáveis e gerenciar o estado da aplicação de forma eficiente.

NEXT.JS

Next.js é um framework React para construção de aplicações web. Ele oferece recursos como renderização do lado do servidor e geração de sites estáticos.

Python

Python é uma linguagem de programação de alto nível, amplamente utilizada para desenvolvimento web, automação, análise de dados e inteligência artificial.

SQL

SQL (Structured Query Language) é uma linguagem de programação usada para gerenciar e manipular bancos de dados relacionais.

AWS

AWS (Amazon Web Services) é uma plataforma de serviços em nuvem que oferece uma ampla gama de serviços, incluindo computação, armazenamento e bancos de dados.

Github

GitHub é uma plataforma de hospedagem de código-fonte e controle de versão usando o Git. É amplamente utilizada para colaboração em projetos de software.

HTML5

HTML5 é uma linguagem de marcação de hipertexto, que usamos para marcar os elementos da página e construí-la.

CSS3

CSS3 é uma linguagem de estilo usada para descrever a apresentação dos elementos da página os estilizando.

JavaScript

JavaScript é uma linguagem de programação interpretada usada no desenvolvimento web para descrever funcionalidades e comportamentos da página.
