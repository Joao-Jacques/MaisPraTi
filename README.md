# Mais Pra Ti

Este projeto é uma pequena galeria web de carros dos anos 2000, desenvolvida para fins educativos e de demonstração de HTML, CSS e JavaScript básico.

## Estrutura do Projeto

- `index.html`: Página inicial do site.
- `grid.html`: Galeria de imagens de carros dos anos 2000.
- `feedback.html`: Página para envio de feedback.
- `listas.html`: Página com listas de hobbies e receitas.
- `styles.css`: Folha de estilos para o site.
- `public/`: Pasta com imagens dos carros exibidos na galeria.

## Funcionalidades

- Navegação entre páginas via menu.
- Galeria de carros com imagens e legendas.
- Menu responsivo (hamburger) para dispositivos móveis.
- Página de feedback para interação do usuário.
- Listas de hobbies e receitas.

## Como usar

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` em seu navegador.
3. Navegue pelas páginas usando o menu.

## Créditos

Imagens utilizadas são apenas para fins ilustrativos.
